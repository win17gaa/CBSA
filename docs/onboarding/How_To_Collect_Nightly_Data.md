# How To Collect Nightly Data

CBSA nightly data collection takes less than 3 minutes.

## Step 1 — Fill the Daily Template
Write:
1. Raw vent
2. Work check
3. Temporal position

## Step 2 — Save the Entry
Save the entry as a timestamped file in your user folder under `/data`.

## Step 3 — Keep It Literal
No emotion labeling.
No interpretation.
No wellness framing.
No extra commentary.

## Step 4 — Submit Nightly
Submit your nightly entry to the shared CBSA data repository.
